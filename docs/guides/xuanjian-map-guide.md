# 玄剑 Map Mod 与玄剑 GIS 使用教程

> 本文面向两种人：**只想在游戏里看地图/贡献地形数据的普通成员**，以及**要绘制城区道路、审核数据的 GIS 编辑员**。阅读时间约 5 分钟。

---

## 一、它是什么

**玄剑 GIS** 是公会自己的世界地理信息系统，和普通小地图插件不同：

- **Xaero 小地图/世界地图**：负责你本地的探索体验（记住走过的地形）。
- **玄剑 Map Mod**：官方客户端，负责把 Minecraft 世界的真实地理数据（高度、生物群系、方块统计）采集下来，上传到公会服务器，并在游戏内叠加公会 GIS 图层。
- **官网 `/gis`**：公会 GIS 的网页端，负责管理、绘制、审核、查看历史与地形分析。

三者关系：**Mod 采集 → 官网存数据 → 官网/Mod 都展示**。地图上的城区、道路、标记不是自动识别的，全部由玩家提交或编辑员绘制。

## 二、网页版：打开玄剑 GIS

### 1. 进入

访问 **https://xuanjian.top/gis**（顶部导航「工具 → 玄剑 GIS」也可进入）。

首次打开会自动选择当前世界（例如「核桃服务器 · hetao-main（当前）」），并且**自动缩放到已有采集数据的范围**。

### 2. 找不到数据怎么办

如果地图一片空白，通常是视野停在了没有数据的区域（默认原点 0,0 附近）。三种方式定位：

| 方式 | 操作 |
|---|---|
| **定位到数据** | 顶部按钮，缩放到当前世界/维度的已采集范围 |
| **跳转坐标** | 顶部输入 `X`、`Z` 后点「跳转坐标」，直接把视野移到该坐标 |
| **链接直达** | 在网址后加参数，例如 `/gis?x=2397&z=123019&zoom=1` |

> 注意：地图只显示**已采集区域**。没走过的地形是「无数据区」，会显示虚线框而不是凭空画成平地。

### 3. 图层开关

地图右上角可开关：**城区边界 / 道路 / 地点标记 / 集市地点**；顶部还有 **等高线** 按钮。

### 4. 绘制城区与道路（需要编辑权限）

1. 顶部点「**绘制城区**」或「**绘制道路**」
2. 在地图上逐点点击（双击结束，Esc 取消，撤销点可回退）
3. 填写名称、类型、颜色（城区）或宽度、道路等级、是否主干道（道路）
4. 保存后会进入 **待审核**；审核通过后才会出现在地图上

**城区与道路的层级**：城区（Polygon）→ 道路（LineString，可归属到某个城区）。道路识别用「宽度缓冲区」判断，不是中心点半径，所以站在路边也能识别为「在道路上」。

### 5. 添加地点标记

普通成员即可提交：顶部「**添加标记**」→ 地图点选位置或直接输入坐标 → 选分类（公共建筑 / 住宅 / 商铺 / 工业 / 农业 / 交通 / 娱乐 / 政府 / 其他）→ 填名称 → 提交审核。

> 标记本身不存图片，介绍和图片请写到 Wiki 页面，然后在标记详情里关联 **Wiki 页面 ID**。

### 6. 审核与版本（需要审核权限）

- 「审核」面板：查看待审核提交，可**通过 / 驳回**
- 每次正式修改都会生成一个**版本**；「属性 → 版本」可以查看历史版本并**回滚**
- 删除是软删除（墓碑），客户端增量同步会收到删除通知

### 7. 地形与等高线

「地形」面板支持：

- **等高线**：5 / 10 / 20 / 50 / 100 米动态等高距，随缩放调整密度
- **高程查询 / 坡度 / 剖面 / 高程分布直方图 / 区域统计 / 山体阴影**
- 重计算走异步任务，不会卡住网站

**只有 Mod 采集过的地方才有地形数据**；没采集的区域会明确标注「无数据」，不会伪造平地。

### 8. 历史地图

「历史」面板可按快照/时间查看历史状态，并与当前地图对比；历史数据不会覆盖当前数据。

### 9. 集市地点选点

如果你要发布店铺：**集市 → 商家 → 位置** 里可以「在地图上选点」，也可以手动输入坐标。旧地点数据已全部保留，不会丢。

## 三、游戏内：安装与使用玄剑 Map Mod

### 1. 版本与安装

| 游戏版本 | 下载 |
|---|---|
| Minecraft **26.2**（Java 25） | Actions Artifacts `xuanjianmap-26-jars` |
| Minecraft **1.21.11**（Java 21） | Actions Artifacts `xuanjianmap-121-jars` |

把 `xuanjianmap-0.1.0.jar` 放进 `.minecraft/mods/`，并确保已安装对应版本的 **Fabric Loader** 和 **Fabric API**。

> 只有服务端装了 Fabric 才能用 Mod 采集；纯原版客户端无法使用。

### 2. 首次配置

进游戏后按 `G` 打开 **玄剑 GIS 界面**，进入「设置」页，确认：

| 配置项 | 建议值 |
|---|---|
| API 地址 | `https://xuanjian.top` |
| 服务器 Key | 与服务端注册的一致（核桃服 = `hetao`） |
| 上传：开 | 打开 |
| 采集：开 | 打开 |
| 采样间隔 / 半径 / 步长 | 默认 `100 tick / 2 chunk / 步长 1`（步长越大越省流量） |
| 上传限速 / 批量 | 默认 60 次/分钟、32 chunk/批 |

### 3. 登录（OAuth，一次性）

1. 点「**生成授权链接（复制）**」，链接会自动复制到剪贴板（失败时看提示里的 txt 路径）
2. 浏览器打开链接 → 登录 xuanjian.top → 授权
3. 回调页会显示一串 **Authorization code**（5 分钟内有效、只能用一次）
4. 回到游戏：
   - 推荐：把 code 粘进输入框 → 点「**登录（输入框）**」
   - 或点「**完成登录（剪贴板）**」
   - 也可以把 code 写进 `config/xuanjianmap/oauth-code.txt` 再点剪贴板登录
5. 成功后显示「已登录：<昵称>」

> 上传还要求账号有 `gis.submit` 权限：**普通成员（Level 0）默认就有**；编辑道路/城区需要额外角色。

### 4. 视界内会发生什么

- 你走近/加载过的区块会被采集并进入上传队列（**不会上传你的实时位置**，也不上传聊天内容）
- HUD 常驻显示：当前城区、当前道路、坐标、维度；按 `=` 展开/收起
- 网络断开/服务器维护不影响本地数据：失败会**指数退避重试**，恢复后自动续传，失败不丢数据
- 「GIS 地图」界面可看自有 **Overlay 图层**（城区多边形、道路、标记、集市地点），支持图层开关与缩放居中

> Mod **不使用也不需要 Xaero 的私有缓存**；即使你装了 Xaero，两者也互不干扰。当前版本不读取 Xaero 缓存、不注入它的渲染管线。

### 5. 本地模式（上传暂停）

出现以下情况时，HUD 会显示「上传：暂停（原因）」并进入**本地模式**（采集、地图、HUD 照常可用，但不上传）：

| 提示 | 原因 | 处理 |
|---|---|---|
| 无 ACTIVE 世界 | 服务端该服务器没有启用世界 | 联系 GIS 管理员在 `/gis → 管理` 注册/启用世界 |
| world_archived | 世界已归档只读 | 同上，注册新世界并设为当前 |
| unauthorized | 未登录/登录过期 | 重新 OAuth 登录 |
| forbidden(required: gis.submit) | 账号没有提交权限 | 让管理员在权限中心给角色 |
| server_not_registered | 服务器 Key 填错或未注册 | 核对设置里的服务器 Key |

进入本地模式后不会反复轰炸接口：绑定失败按 60s→300s 退避重试；世界恢复 ACTIVE 后 5 分钟内自动恢复上传。

## 四、权限说明

| 能做什么 | 需要的权限 | 谁能拿到 |
|---|---|---|
| 进入 GIS 客户端采集、提交标记/地形 | `gis.submit` | **所有登录成员（Level 0 默认）** |
| 查看 GIS 管理数据、管理面板 | `gis.access` | 授予 gis.access 的角色 |
| 绘制/编辑道路 | `gis.road.edit` | 「GIS 编辑员」等角色 |
| 绘制/编辑城区 | `gis.district.edit` | 「GIS 编辑员」等角色 |
| 审核发布、回滚他人提交 | `gis.object.review` | 「GIS 管理员」等角色 |
| 注册世界、地形任务、全局管理 | `gis.admin` | Level 1 / GIS 管理员 |

角色在 **/admin → 权限中心** 分配；模块角色只能授予本模块权限（GIS 角色只能给 `gis.*`）。

## 五、常见问题

**Q：网页地图打开是空白的？**
先点顶部「定位到数据」或「跳转坐标」。世界有数据但视野不在数据区时，地图就是空的，这是按需加载的正常行为。

**Q：空间搜索搜不到已知地点？**
确认选对了世界与维度；搜索默认在**整个世界内**找已发布对象。如果勾了「仅搜索当前视野范围」，要先缩放到目标区域。

**Q：等高线/地形没有？**
只有 Mod 采集过的区块才有高程数据；没数据会显示「无数据区」而不是平地。

**Q：游戏里 HUD 一直显示「未知区域 · 无道路」？**
说明该位置还没有已发布的城区/道路。编辑员绘制并审核通过后，进入该区域才会显示名称。

**Q：上传一直暂停？**
看 HUD 括号里的错误码，对照上面「本地模式」表格处理；多数是「世界未设为 ACTIVE」。

**Q：换服务器/换世界要注意什么？**
客户端不能自己创建世界，世界的 `worldId/worldKey` 必须来自服务端 bootstrap；换服后如果该服未注册 GIS，会自动进入本地模式。

## 六、快速上手清单

1. **普通成员**：装对应版本 jar → 设置 API + 服务器 Key → OAuth 登录 → 正常跑图（地形自动上传）→ 想留个纪念就在网页「添加标记」。
2. **编辑员**：登录网页 `/gis` → 定位到数据 → 绘制城区/道路 → 提交审核 → 发布后在游戏内 HUD 与地图即可看到。
3. **管理员**：`/gis → 管理` 注册服务器与世界（设为 ACTIVE）→ 地形任务按需预热 → 审核队列处理提交。

有问题可在群里 @ 管理员，或在网站「反馈」提交。
